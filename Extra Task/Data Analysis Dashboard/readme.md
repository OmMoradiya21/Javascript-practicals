# Data Analysis Dashboard

- Data is about year 2025 sells and profit - month wise.
- sells and profit are propotional to each other
- it show total, average, minimum, maximum profit and charts.
- There are three chart:
  1. Profit vs Month
  2. Sells vs Month
  3. Profit vs Sells

- There are Multiple Options of Chart Type to visualize:
  1. Bar
  2. Line
  3. Pie
  4. Doughnut
