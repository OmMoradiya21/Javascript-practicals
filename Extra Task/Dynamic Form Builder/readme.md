# Dynamic Form Builder

Work-Flow:

- On click: Add Button --> asks
  1. How Many Field You Want? = n (set limit 1-10)
  2. Enter Label Name: (more than 2 char)
  3. Enter Input Type: -- > go to step 2

  4. Enter multiple option: (if Input Type = radio / checkbox)
     - enter option with (,) seperated -(ex : cricket, football, vollyball) -- > go to step 2

- Loop run (n) times and form generate dynamically.
- Valid fields are = [
  "color",
  "date",
  "email",
  "file",
  "image",
  "month",
  "number",
  "password",
  "range",
  "reset",
  "search",
  "tel",
  "text",
  "time",
  "url",
  "week",
  "checkbox",
  "radio",
  ]
