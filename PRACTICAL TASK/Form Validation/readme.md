# Form Validation

A simple web application that validates user input for name, email, password, and confirm password fields.

## Features

- Validates name to include only letters and spaces
- Checks email format for validity
- Enforces strong password rules
- Ensures confirm password matches the entered password
- Displays live validation status messages

## How to Use

1. Open `index.html` in your browser.
2. Enter your name, email, password, and confirm password.
3. Fix any validation messages until all fields are valid.
4. Submit the form to see the success message.

## Files

- `index.html` - form structure
- `style.css` - form styling
- `script.js` - validation logic
- `readme.md` - project description

## Notes

- The form uses client-side validation only.
- The submit button becomes enabled when all fields are valid.
